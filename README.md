# DevDuck

DevDuck is a developer CLI that helps you understand errors
without immediately solving them for you.

> Understand the error. Keep the fun.

## Status

🚧 Early development

Currently working on:

- `duck <command> [args...]`
- Python support
- Error parsing
- Level-based hints
- Local explanations
- AI fallback

## Example

```bash
duck python main.py
